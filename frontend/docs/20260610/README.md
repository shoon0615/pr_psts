# 🛠️ 기술 스택 (Tech Stack)

이 프로젝트의 기술 스택을 분야별로 정리한 문서입니다.

### ⚙️ 개발 환경 & 코어
- **Framework** : Next.js (App Router) -> v15.1.6
- **Library** : React -> v19.2.3
- **Language** : TypeScript -> v5.x
- **Package Manager** : pnpm

### 🎨 UI & Styling
- **Styling** : Tailwind CSS -> v4.0.0
- **UI Components** : Shadcn UI, Radix UI, Base UI
- **Icons** : Lucide React
- **Animations** : tw-animate-css, Vaul (Drawer)

### 🔄 데이터 통신 & 상태 관리
- **Data Fetching** : TanStack Query -> v5.99.0
- **HTTP Client** : Axios -> v1.15.0
- **URL State** : nuqs -> v2.8.9
- **Form Management** : React Hook Form -> v7.72.1
- **Schema Validation** : Zod (via resolvers)

### 🧪 테스트 (Testing)
- **Unit/Integration** : Vitest, Testing Library
- **E2E** : Playwright, Cypress
- **API Mocking** : MSW (Mock Service Worker)
- **Mock Server** : JSON Server

### 🔐 인증 및 보안
- **Authentication** : NextAuth.js -> v5.0.0-beta.31
- **Encryption** : bcryptjs -> v3.0.3

### 🔧 유틸리티 & 도구
- **Code Quality** : ESLint, Prettier
- **Date Utility** : date-fns -> v4.1.0
- **Theme** : next-themes
- **Execution** : Concurrently (Multi-command execution)
